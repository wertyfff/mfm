# МФМ — Мировой фестиваль моды

Сайт фестиваля моды в Париже, 21–22 ноября 2026 года.

Статический сайт без сборки: `index.html`, стили в `css/style.css`, скрипты в `js/main.js`.
Чтобы посмотреть локально, достаточно открыть `index.html` через любой статический сервер,
например `python -m http.server`.
